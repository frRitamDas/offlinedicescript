What the website source actually shows

The browser creates a random 10-character session ID using crypto.getRandomValues, then calls the Firebase function rollDiceSecure with that ID and the dice count. The server returns the colors and roll ID. That server-side function’s implementation is not included in the browser source, and the session ID alone does not reveal the next roll. This analyzer only summarizes outcomes you provide.

📊 What the estimate means

It identifies the most frequent colors in the history you paste and shows their observed share. That is a description of past rolls, not evidence those colors will come next.

🎲 What the source cannot do

There is no client-side ID-to-color formula to reproduce. If rolls are fair and independent, every color remains 1 in 6 on each die.
